# קלפיות AI — אחוזי הצבעה לכנסת ה-26

עיר תלת-ממדית של כל היישובים שוועדת הבחירות מפרסמת עבורם אחוז הצבעה ביום הבחירות (27.10.2026).
כל מגדל הוא יישוב: גובה = אחוז ההצבעה, רוחב = מספר הבוחרים, צבע = פרופיל ההצבעה של היישוב ב-2022.

## מבנה

| נתיב | תפקיד |
|---|---|
| `src/page.html` | הדף כולו (עיצוב, מסכים, עיר תלת-ממדית, מפענח .mht, "שאל את העיר"). הנתונים מוזרקים ב-build. |
| `data/cls.json` | סיווג 1,215 יישובים: מגזר, סוג, פרופיל, בעלי זכות 2022, תוצאת 2022, חלוקת גושים. נוצר על ידי `scripts/classify.mjs`. |
| `data/cls-555.json` | הסיווג העריכתי המקורי של 555 היישובים הראשונים (מגזר, סוג). |
| `data/expc-2022.csv` | תוצאות הכנסת ה-25 לפי יישוב, הקובץ הרשמי של ועדת הבחירות. |
| `data/snap-1249.json`, `data/snap-1645.json` | נקודות הזמן של יום הבחירות (12:49 — 555 יישובים; 16:45 — 1,215 יישובים). |
| `data/ref-2022.json` | אחוזי ההצבעה הארציים לפי שעה ב-2022, להשוואה "באותה שעה". |
| `scripts/build.mjs` | בונה `dist/artifact.html` (לפרסום ב-claude.ai) ו-`dist/index.html` (דף עצמאי). |
| `scripts/shoot.mjs` | צילומי מסך אמיתיים (Playwright): נייד 412×860 ומחשב 1366×860, כהה ובהיר, כל המסכים, ודף מגע. |

## הרצה

```bash
npm install
npm run classify   # מחדש את data/cls.json מהקובץ הרשמי + הסיווג העריכתי
npm run build      # dist/artifact.html + dist/index.html
npm run shoot      # qa/shots/*.png + contact-sheet.jpg
```

## מאומת מול הערכה

- **מאומת:** אחוזי ההצבעה לפי יישוב ושעה (ועדת הבחירות), בעלי זכות ותוצאות 2022 (expc.csv).
- **הערכה:** בוחרים 2026 = בעלי זכות 2022 × 1.08; פרופיל ההצבעה (כללים על חלוקת הקולות 2022); סיווג מגזר/סוג ל-660 היישובים שנוספו ב-16:45 (כללי שם, גודל ותוצאה — לא נבדק ידנית); 2022 "באותה שעה" בין שעות עגולות — חישוב ליניארי.

## עדכון נקודת זמן

שומרים את דף "אחוזי הצבעה לפי יישוב" מאתר הוועדה כקובץ `.mht` (כרום: שמור דף בשם → דף שלם, קובץ יחיד) ומעלים דרך כפתור "+" במסך "עכשיו". כשהדף פתוח בתוך claude.ai אצל מנהל הדף, הנקודה נשמרת לכל מי שפותח את הקישור.
